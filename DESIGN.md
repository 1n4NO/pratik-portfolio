# Design System

## Direction

An independent product studio portfolio inspired by Piñt's bold, image-led editorial pacing. The site uses oversized statements, dark graphite fields, warm mineral neutrals, thin rules, and large project imagery. It should feel authored and direct, not like a technical dashboard.

## Typography

- Keep the existing Gloock, Archivo, and Martian Mono font families.
- All letter spacing is normal.
- Display and heading line height is 1.2.
- Body, labels, buttons, captions, and supporting copy use 1.5 line height.
- Gloock carries primary statements and project names; Archivo carries reading copy; Martian Mono is reserved for compact metadata.

## Color

- Main field: `#161512`
- Raised field: `#24231f`
- Warm text: `#eaeaec`
- Muted text: `#a4a09a`
- Rules: `#46443f`
- Accent: `#ac9888`
- Light editorial field: `#d8d4ce`

## Composition

- Content spans a wide studio canvas with restrained gutters.
- The homepage opens with one dominant statement and an immediate path to work.
- Project sections are large, image-first compositions separated by rules rather than card grids.
- Alternate dark and mineral surfaces to pace the scroll.
- Navigation is compact and visually secondary to the work.

## Components and Motion

- Buttons are compact rectangular controls with a subtle radius, not pills.
- Project media uses shallow framing and controlled crop; avoid dashboard-like glass panels.
- One continuous horizontal work reel supplies ambient motion. Other motion is limited to image scale, reveal, and directional link movement.
- Reduced-motion settings remove continuous movement without hiding content.

## Responsive Rules

- Large split compositions collapse to a single reading column.
- Headlines scale down without changing line-height or letter spacing.
- Project metadata follows imagery on narrow screens.
- Navigation keeps the mark, essential links, and search accessible without crowding.
