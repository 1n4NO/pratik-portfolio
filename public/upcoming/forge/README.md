# Forge screenshot slots

Place three product screenshots in this directory using these exact filenames:

1. `01-overview.png` — the primary Forge workspace with a project selected. Use a 16:9 capture, ideally 1920×1080 or larger.
2. `02-architect.png` — the Architect knowledge graph or decision-space view. Use a 4:3 capture, ideally 1600×1200 or larger.
3. `03-foundry.png` — the Foundry workflow builder with approvals, tools, or budgets visible. Use a 4:3 capture, ideally 1600×1200 or larger.

Use PNG with the exact filenames above. Capture only the product window—avoid browser chrome, desktop wallpaper, or unrelated windows. Once the files exist at these paths, the portfolio placeholders disappear automatically.
